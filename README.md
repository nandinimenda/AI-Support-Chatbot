# AI Support Chatbot

An AI-powered support chatbot that allows users to ask questions and receive AI-generated responses.

## Features

- User-friendly chat interface
- AI-generated responses
- Real-time message display
- Enter key support
- Clear chat option

## Technologies Used

- React.js
- JavaScript
- Node.js
- Express.js
- CSS
- AI API
